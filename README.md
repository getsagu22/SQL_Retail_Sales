# SQL Retail Sales Analysis

## 📌 Project Overview
This project demonstrates SQL skills in **data cleaning, exploration, and analysis** using a retail sales dataset. It highlights the ability to write efficient queries, handle missing values, and generate business insights — skills valuable for data analyst and business intelligence roles.

## 🛠️ Tech Stack
- SQL (PostgreSQL / MySQL compatible)
- Retail sales dataset

## 📊 Key Features
- Data Cleaning: Handling null values and duplicates
- Data Exploration: Customer demographics, categories and sales trends
- Business Insights:
  - Top-selling categories
  - Best-performing months
  - Customer segmentation
  - Shift-based sales analysis

## 🔍 Sample Queries
- Find top 5 customers by sales
- Calculate monthly average sales and identify best-selling month
- Analyze sales by category and gender
- Identify high-value transactions (>1000)

## 🎯 Why This Project?
- Ability to derive actionable insights from raw data
- Practical knowledge of business-oriented analysis

- Total customers: `X`
- Unique categories: `Y`
- Best-selling month: `November 2022`
